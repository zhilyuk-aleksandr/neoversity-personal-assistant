# Персональний помічник

Командний проєкт курсу Python Programming, Neoversity. Консольний застосунок для адресної книги й нотаток із локальним збереженням.

## Як запустити

Потрібен Python 3.12 або новіший. Відкрийте термінал у корені проєкту.

```sh
python3 -m assistant
```

На macOS можна відкрити `Запустити.command` подвійним кліком, на Windows — `Запустити.bat`. У терміналі Windows також працює `py -3 -m assistant`.

Введіть `add-contact` або `add-note`, щоб помічник запитав поля по черзі. Команда `help` відкриває довідку, а `exit` завершує сеанс. За замовчуванням дані зберігаються у файлі `~/.personal_assistant/assistant.json`.

Пакет можна встановити у власне віртуальне оточення через `python -m pip install .` і запускати командою `assistant`. [Повна інструкція, приклади команд і формат даних](assistant/README.md).

## Як перевірити

```sh
python3 -m unittest discover -s assistant/tests
```
